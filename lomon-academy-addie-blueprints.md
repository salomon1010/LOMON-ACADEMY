## ADDIE PHASE 4: IMPLEMENT — Weekly Execution Rhythm

### Academy Block Daily Structure (90 min)
```
4:45 PM  → Open Google Calendar / Dashboard — see today's targets (5 min)
4:50 PM  → IXL session — work current week's target skill (35 min)
5:25 PM  → Claude Tutor session — weak strand explanation + 3 problems (20 min)
5:45 PM  → Writing / Critical Thinking prompt (20 min)
6:05 PM  → Log SmartScores in Google Sheets Dashboard (10 min)
6:15 PM  → Block ends. External activities begin.
```

### Tired Day Mode (60 min — use 1x/week max)
```
4:45 PM  → IXL only — top 1 target skill (35 min)
5:20 PM  → Claude single-skill explanation (15 min)
5:35 PM  → 2 sentences in writing journal (10 min)
5:45 PM  → Block ends early
```

### Sunday Prep (10 min for Salomon)
1. Check Friday SmartScores in Sheets
2. Fire Friday Report prompt at Claude
3. Review next week's milestone gate
4. Post Monday assignment in Google Classroom
